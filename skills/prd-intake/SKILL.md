# PRD Intake

Use this when a feature starts from a Notion PRD.

## Goal

Turn a PRD into an implementation-ready summary without starting code too early.

## Output

- concise problem statement
- user outcome
- scope and non-goals
- open questions
- dependencies
- recommended next Linear task title

## Rules

1. Preserve the PRD intent instead of translating it into premature architecture.
2. Call out ambiguity clearly.
3. Separate product requirements from implementation ideas.
