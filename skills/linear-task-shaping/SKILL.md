# Linear Task Shaping

Use this when a Notion PRD needs to become one or more actionable Linear tasks.

## Goal

Produce tasks that are small enough to execute and clear enough to validate.

## Output

- issue title
- short description
- linked PRD
- acceptance criteria
- dependencies
- recommended labels or priority

## Rules

1. Do not create vague umbrella tasks if the work can be split into meaningful steps.
2. Keep each task outcome-based.
3. Put execution detail in the plan, not in the ticket title.
