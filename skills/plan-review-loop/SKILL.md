# Plan Review Loop

Use this before implementation starts.

## Loop

1. draft the plan
2. review the plan for scope, risk, and validation quality
3. revise the plan
4. repeat until the plan is ready for approval
5. do not implement before approval

## Review Questions

- is the scope tight?
- are non-goals explicit?
- does the order of work reduce risk?
- are validation steps real and sufficient?
- are there hidden dependencies?

## Approval Bar

The plan is ready only when a reviewer can understand:

- what will change
- what will not change
- how success will be checked
