# PRD To Linear

Use this flow whenever a new feature or significant improvement starts.

## Step 1: PRD in Notion

The PRD should clearly cover:

- problem statement
- target user
- desired outcome
- scope
- non-goals
- UX notes or references
- rollout or validation notes

## Step 2: Create Linear Task

Each Linear task should include:

- a concise problem-focused title
- PRD link
- summary of desired user outcome
- scope boundaries
- dependencies or blockers
- acceptance criteria

## Step 3: Planning Trigger

Planning can start only after:

- the PRD is understandable
- the Linear task is created
- success criteria are concrete enough to validate
