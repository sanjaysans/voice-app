# Manual Review Checklist

Use this before approving merge for any user-facing change.

## Product

- does the flow match the approved PRD?
- are labels and states understandable?
- are empty, loading, error, and success states handled?

## UX

- is layout consistent with the current design system?
- does it work at the target desktop widths?
- are the main actions obvious?

## Engineering

- was the implementation verified locally?
- are assumptions and limitations documented?
- are follow-up tasks called out explicitly?
